# Naučimo Hrvatski

A family Croatian learning web app: daily lessons, spaced review, conversations, grammar and pronunciation, with recorded audio.

Live site: https://jasonleonard618-ux.github.io/naucimo-hrvatski/

Progress is saved in each browser on its own device.

The site is built from the app's source with `tools/build-site.sh`, which adds the HTML document head that the original artifact host supplied.
